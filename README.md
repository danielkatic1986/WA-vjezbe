# Web aplikacije — Vježbe

Repozitorij s rješenjima vježbi iz kolegija **Web aplikacije**. Svaka vježba nalazi se
u zasebnom direktoriju (`wa-vjezbe-1`, `wa-vjezbe-2`, ...) koji sadrži vlastiti
`README.md`, izvorni kod i prateće materijale.

## O kolegiju

| | |
| --- | --- |
| **Kolegij** | Web aplikacije (WA – 199769) |
| **Ustanova** | Sveučilište Jurja Dobrile u Puli, Fakultet informatike u Puli |
| **Nositelj** | doc. dr. sc. Nikola Tanković |
| **Asistent** | Luka Blašković, mag. inf. |

Kolegij se bavi razvojem **poslužiteljskog sloja** web aplikacija korištenjem
**Node.js-a** i web okvira **Express.js**.

